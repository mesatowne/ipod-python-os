# ipod-python-os

## Quick Build
```bash
git clone https://github.com/mesatowne/ipod-python-os.git
cd buildroot
cp ../ipod-python-os/.config .
make -j$(nproc)
```

## Documentation

This repository documents the iPod Python OS build system. The Yemen offline map workflow now lives in the standalone `yemen-offline-map/` project directory so it can be published independently.
